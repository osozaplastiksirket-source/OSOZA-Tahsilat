OSOZA Tahsilat Android Studio Projesi

Android Studio ile klasoru acin. Gradle senkronizasyonundan sonra Build > Build APK(s) secin.
Olusan APK: app/build/outputs/apk/debug/app-debug.apk

Kayitlar uygulamanin ozel depolamasinda saklanir. Uygulamayi kaldirmak kayitlari silebilir. JPEG Android 10+ icin Downloads/OSOZA klasorune yazilir. Android 8-9 icin uygulamaya ozel Pictures/OSOZA klasorune yazilir.

Not: Bu paket APK degil, APK uretmeye hazir kaynak projedir.
